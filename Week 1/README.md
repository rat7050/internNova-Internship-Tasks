# 🐍 Python Programming Assignment

## 📌 About the Project

This repository contains my Python programming assignments covering fundamental concepts of Python. These tasks helped me understand Python basics through practical coding exercises and a mini project.

The assignment includes **9 tasks**, starting from basic Python syntax and moving towards functions, collections, file handling, and a Student Record Management System.

## 🎯 Objectives

- Understand Python fundamentals.
- Learn variables and different data types.
- Practice operators and conditional statements.
- Understand loops and user-defined functions.
- Work with strings and Python collections.
- Learn basic file handling.
- Develop a simple real-world Python project.

## ⭐ Mini Project: Student Record Management System

The final task is a menu-driven Student Record Management System developed using Python.

### Features

- ➕ Add new student records.
- 📋 Display all student records.
- 🔍 Search students by name.
- 🗑️ Delete student records using roll number.
- 🚪 Exit the application.

### Concepts Used

- Lists
- Dictionaries
- Functions
- Conditional Statements
- While Loop
- User Input

**Note:** Student records are stored in memory using a Python list and are not permanently saved after the program exits.
