# InternNova Week 2 Assignment
## NumPy and Pandas for Data Analytics

### About This Project

This project is part of my Week 2 internship assignment at InternNova. In this assignment, I practised NumPy and Pandas using Python.

I used these libraries to create arrays, store employee information, read CSV files, clean data and perform basic analysis.

### Tasks Completed

**Task 1: Introduction to NumPy**

Created one-dimensional and two-dimensional arrays. Checked their shape, size and data type.

**Task 2: Array Indexing, Slicing and Reshaping**

Accessed array elements, selected values using slicing and changed the array shape using `reshape()`.

**Task 3: NumPy Mathematical Operations**

Performed addition, subtraction, multiplication and division. Also calculated sum, average, minimum and maximum values.

**Task 4: Pandas Series and DataFrame**

Created a Pandas Series and an employee DataFrame. Displayed column names and index, and added a new column.

**Task 5: Reading and Inspecting CSV Files**

Read employee data from a CSV file and checked its first rows, last rows, data types and statistical information.

**Task 6: Selecting, Filtering and Sorting Data**

Selected specific columns, filtered employees by salary and department, and sorted employee records.

**Task 7: Handling Missing Values**

Checked missing values in the dataset and filled empty Age and Salary values using their average.

**Task 8: Merging, Grouping and Pivot Tables**

Combined employee and department data, calculated department-wise average salary and created a pivot table.

**Task 9: Exporting Data**

Added a Bonus column and saved the updated employee data into CSV and Excel files.

**Task 10: Employee Data Analysis**

Analysed employee records to find total employees, average salary, highest salary, lowest salary and department-wise employee count.

### Important Functions Used

| Function | What it does |
|---|---|
| `np.array()` | Creates a NumPy array. |
| `shape` | Shows array dimensions. |
| `size` | Counts total elements. |
| `dtype` | Shows the data type. |
| `reshape()` | Changes array shape. |
| `np.sum()` | Calculates the total. |
| `np.mean()` | Calculates the average. |
| `np.max()` | Finds the highest value. |
| `np.min()` | Finds the lowest value. |
| `pd.Series()` | Creates a Pandas Series. |
| `pd.DataFrame()` | Creates a DataFrame. |
| `pd.read_csv()` | Reads a CSV file. |
| `head()` | Shows the first five rows. |
| `tail()` | Shows the last five rows. |
| `info()` | Shows column and data type information. |
| `describe()` | Gives a statistical summary. |
| `isnull()` | Checks missing values. |
| `fillna()` | Fills missing values. |
| `sort_values()` | Sorts records. |
| `groupby()` | Groups records. |
| `pd.merge()` | Combines two DataFrames. |
| `pivot_table()` | Creates a summary table. |
| `to_csv()` | Saves data as CSV. |
| `to_excel()` | Saves data as Excel. |
| `value_counts()` | Counts repeated values. |
